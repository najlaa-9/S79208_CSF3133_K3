About the Event

Programming Workshop 2026 is a one-day event organised by the Faculty of Computing to improve students' programming skills.

Introduction to Web Development

Students will learn the basics of HTML and how to create a simple web page.

Java Programming Workshop

Students will learn basic Java programming and practise solving programming problems.
